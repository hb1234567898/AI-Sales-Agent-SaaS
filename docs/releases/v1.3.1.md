# 1.3.1 发布说明

本次为界面与桌面图标修复，按补丁版本从 1.3.0 升级到 1.3.1。
计划发布标签为 `desktop-v1.3.1`，正式状态以 GitHub Release 为准。

## 修复

- 优化工作台“我的跟进待办”：分离任务、客户、来源和到期状态，去除默认链接下划线。
- 独立显示今日到期与逾期数量，补全悬停、键盘焦点、加载、空态和错误重试状态。
- 兼容手机窄屏和长标题，任务完成继续使用原有版本校验和计数刷新逻辑。
- Windows 桌面快捷方式与可执行文件保留蓝底图标，运行时窗口和任务栏使用独立的深色底图标。

## 验证

- 前端 109 项测试、lint 和生产构建通过。
- Rust 图标测试和格式检查通过，未增加运行时图片解码依赖。
- 在 1920、1440、390、320 像素宽度下检查常规和长文本布局，以及空态、错误态和完成任务交互。

## 升级与回滚

本次没有数据库迁移和业务 API 变更。网页界面需部署新的前端静态文件；
桌面图标变更必须通过重新构建的 1.3.1 安装包生效。
正式包由 GitHub Actions 生成 updater 签名及 latest.json，不能将本地未签名测试包用于自动更新。

遇到桌面图标缓存未刷新的情况，可关闭并重新打开应用；旧的任务栏固定项仍可能保留 Windows 缓存。
网页可切回上版静态文件；桌面修复应继续提升补丁版本，低版本不会触发自动降级。
