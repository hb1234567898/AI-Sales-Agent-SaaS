# AI Sales Agent 1.4.0

发布日期：2026-11-12。

## 新功能与改进

- 新增产品与价格表、报价单版本及客户确认、合同签约与分期回款管理。
- 今日工作台使用实时跟进、审批和 Agent 运行数据；合并重复审批区块，提供邮件、报价、合同和知识库入口。
- 顶部支持功能导航搜索及 Ctrl/Cmd K 快捷键，按角色过滤管理入口。
- 优化客户编辑表单和窄屏布局；管理员可确认后软删除客户，已有报价时保留档案。
- 修复空正文、摘要或异常时间导致的互动记录白屏，保留 AI 分析更新后的当前标签页。
- 修复线索保存失败时未处理的异常，保留错误提示与表单。

## 权限修复

- `/api/public/**` 用于登录、公钥和基础健康检查；`/api/v1/**` 的业务接口统一要求登录。
- 客户、联系人、互动和聊天分析使用登录账号所属组织，MCP 助手沿用相同组织和权限校验。
- 只读成员和未知角色不能直接新增、编辑、导入或转化 CRM 数据，也不能执行聊天分析及应用结果。
- 助手遇到多个相似客户时要求明确名称，避免创建重复档案。

## 升级说明

- 服务端、网页和桌面客户端配套更新。登录、刷新和公钥地址改为 `/api/public/auth/`，当前会话与退出仍位于 `/api/v1/auth/`；旧桌面客户端需更新到 1.4.0 后使用登录功能。
- 健康探针改为 `/api/public/health`，不返回详细信息。
- 服务端包含截至 V19 的 Flyway 迁移；从 1.3.1 升级前应备份数据库。数据库迁移不能通过切换应用版本回滚。
- 本次未修改 Python AI 服务源码；继续使用已部署的 AI 服务。
