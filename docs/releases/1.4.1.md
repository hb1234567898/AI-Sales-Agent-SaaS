# AI Sales Agent 1.4.1

发布日期：2026-11-12。

## 知识库预览

- 支持 Markdown 标题、列表、表格、引用、代码块、链接、图片和任务清单，并可切换预览与源码。
- Markdown、TXT 和手动录入资料按完整原文渲染，避免检索片段的重叠和截断破坏表格或代码块；PDF、DOCX 保留解析片段和页码。
- 知识问答结果同步支持 Markdown；中文原文读取兼容 UTF-8、UTF-8 BOM 和 GB18030。
- 原文通过现有登录鉴权接口读取；预览跳过原始 HTML 并过滤危险链接。原文加载失败时可重试。

## 功能引导

- 新增客户邮件同步、关联、意图分析、回复审批与发送结果核对引导。
- 更新跟进任务说明，覆盖手动新建、任务范围、完成、延期、取消、自动规则与站内提醒。
- 补充 IMAP 收信配置、管理员删除客户、功能搜索及 Markdown 预览说明，并按销售流程调整顺序。
- 根据引导内容自动识别版本变化，提示“有更新”，重置过时步骤并保留其他有效进度；进度仍在当前浏览会话内保存。
- 按各角色导航入口检查引导覆盖，防止新增菜单时漏写引导；修复抽屉打开后高亮到背后列表的问题。

## 升级与回滚

- 1.4.0 客户端可通过应用内更新升级，也可下载安装包覆盖安装。
- 本次无数据库迁移，不修改后端和 Python AI 服务源码，沿用 1.4.0 的登录接口与权限规则。
- 需要回滚时恢复 1.4.0 网页和桌面版本；桌面降级需手动安装旧版本。
