# 新旧功能与工作台衔接检查

## 已完成

- 今日工作台：删除写死的客户数、触达率、审批和运行记录，复用跟进统计、审批、Agent 运行和模型配置接口。游客数据继续由现有游客 API 层提供。
- 跟进指标：与“我的跟进待办”共用查询缓存，完成任务后同步更新。累计完成与今日到期分别标明统计范围；缺失值显示 —。
- 审批：合并重复的 AI 动作审核和人工审批区块，复用顶部审批查询，保留统一审批中心作为处理入口。
- 新功能入口：首页加入 MCP 助手、客户邮件、报价、合同回款和企业知识库入口。销售预测移至智能工具与管理分组。
- 顶部搜索：将没有行为的全局搜索改为真实的功能导航搜索，支持 Ctrl/Cmd K、Enter 与 Escape，按角色过滤管理入口。此处不搜索业务记录。
- 界面：改进侧栏滚动、窄屏搜索和运行记录列布局，保留现有设计体系。
- 功能指南：同步更新首页统计、跟进任务和审批的使用说明。

## 仍保留的演示功能

销售预测使用 mockOpportunities 和 salesTargets，效果分析使用固定周活动及漏斗数据。两页继续显示演示标识；没有将前端样本计算伪装为真实业务统计。后续接入需要明确销售目标、周期统计和效果归因口径及对应接口。
